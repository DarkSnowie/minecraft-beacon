# Minecraft Beacon

An offline Minecraft Bedrock companion for tracking:

- 🏆 Achievements
- 🌾 Farms
- 📀 Collections
- 🗺️ Progress Roadmap
- 👨 Villagers
- 📦 Storage Planning
- 📝 Notes

## Features

- Offline
- Automatic Saving
- Responsive Design
- Installable (PWA)
- Open Source
